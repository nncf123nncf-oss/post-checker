# 投稿前チェック（post-checker）

投稿する文章を貼ると、URLの形・全角と半角の混在・日付や数字・ハッシュタグ・文字数を、決まったルールで見て、気になる場所に印をつける静的ページです（100日100プロダクト Day067）。

- 文章はブラウザの中だけで処理し、サーバーには送信せず、保存もしません（通信は閲覧数の計測のみ）
- AIは使っていません（ルールベース）
- 誤字・名前の間違い・事実の誤りは見つけられません。「見つからなかった」は「問題がない」という意味ではありません
- 文字数の280ユニットは目安です。超えていても警告にとどめます（数え方がXと完全に同じとは限りません）

## 使い方
`index.html` をブラウザで開き、文章を貼ります。ビルド不要（1ファイル）。

## 開発用（source/）
- `index.src.html` と `wide-ranges.txt` から `build.py` が `index.html` を作ります（文字幅の表を埋め込むため）
- `run-checks.js`: 検査ルールの検算（`node source/run-checks.js`）。`make-corpus.py` が作る `corpus.json`（Pythonの文字幅）と数え方を照合
- `e2e.js`: 実ブラウザ（Chrome headless）での検算。`shoot.js`: 投稿カード用の画面撮影
